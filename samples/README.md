# Sample captures

Capture files for the tests, and for checking pilotfish's output against
`capinfos` and `tshark -r`.

- Public captures, such as those from the Wireshark sample captures page, go in
  this folder. Note where each one came from.
- Captures you record yourself go in `samples/private/`, which git ignores.
  Your own traffic can include IP addresses, hostnames and DNS lookups that you
  may not want to publish.
